# Security notes

RobTech Phase 2 intentionally does NOT execute arbitrary shell commands generated by the model.

Do not expose the workspace directory as a public static directory.

Before adding a shell/code execution tool:
- Run every project inside an isolated container.
- Set CPU/RAM/time limits.
- Restrict outbound network access.
- Use a non-root user.
- Use an ephemeral filesystem.
- Never mount the RobTech host filesystem.
- Never expose environment variables or API keys to generated code.
- Add authentication, quotas and abuse controls.
